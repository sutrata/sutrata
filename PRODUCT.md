# Sutrata Product Context

## Mission & Purpose
Sutrata is a dedicated, distraction-free screenplay editor engineered specifically for multilingual storytelling (Latin and Indic/Unicode scripts including Hindi, Tamil, Telugu, Kannada, Malayalam, Bengali, Gujarati, Gurmukhi, Odia).

It bridges the gap between the speed of plain-text markup (via the open **Sutra** specification) and the structured visual presentation of classic industry standard screenplay typography.

## Target Audience & Personas
- **Alex (Professional Screenwriter / Filmmaker)**:
  - Requires keyboard-first velocity, distraction-free focus, zero clunky modal interruptions, and strict adherence to industry page layout conventions (Courier Prime 12pt, exact indentation standards).
  - Values native export fidelity (Fountain, DOCX, industry PDF).
- **Priya (Multilingual Scriptwriter / Regional Cinema Storyteller)**:
  - Writes scripts in bilingual or polyglot formats (e.g., English scene headings and character names with Devanagari or Tamil dialogue).
  - Needs effortless transliteration (ISO 15919), flawless Indic font rendering (zero tofu / missing glyphs), and grapheme-cluster-aware navigation.
- **Jordan (First-Time Screenwriter)**:
  - Seeks an approachable, intuitive writing interface with clear visual hierarchy, quick templates, and helpful element tooltips.

## App Archetype: Operate Mode
Sutrata is an **Operate-mode application**:
- The screenwriting page is the primary workspace and focal point.
- Toolbars and side navigation panels are quiet, high-density, and non-distracting.
- Visual chrome recedes into the background so creative writing flow is sustained.
- No SaaS clichés, no unnecessary decorative illustrations, no gamification badges.

## Core Features
- **Sutra Plain-Text Core**: Single source of truth text with instantaneous parsing and AST projection.
- **Dual Visual Presentation**: Interactive WYSIWYG formatted screenplay editor alongside a plain-text source view.
- **Scene Navigator**: Drag-and-drop structural navigator for scenes, synopsis editing, scene locks, and status tags.
- **Multilingual Support**: First-class Indic script typography, ISO transliteration, and localized UI.
- **Industry Exporting**: Production reports (cast list, shot list, one-liners) and export to Fountain, PDF, and DOCX.
